# h5-server 设计方案

## 需求和背景

获取作品，并通过 h5 形式渲染给用户，同时支持其查看，分享，点击跳转等，以及第三方统计渠道

## 技术选型

- Vue3 ssr
  - 流量大，交互简单
- 缓存
  - 流量大时，频繁访问数据库是一个性能瓶颈
  - 使用 redis 缓存，可解决这个问题
  - 何时清除缓存：
    - 重新发布
    - 强制下线
- 网页前端
  - 统计，分渠道统计
  - 渠道参数检查
  - 事件
  - 微信分享（分享回流）
