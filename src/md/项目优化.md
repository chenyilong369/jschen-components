## 体积优化
- 优化前 2.3 mb
- package.json 中 dependencies 和 devDependencies 需要放对，仅开发需要的都放在devDependencies中
- 是否有重复模块，以及功能大体相似的文件。
  - lodash 和 lodash-es
  - lodash-es 体积更小，使用 lodash-es，体会tree-shaking 红利
- 检查是否有没有用到的模块
- 将ant-design-vue 全量引入，导致其占用 1.42 mb，
  - 按需加载，将用到的组件提取到一个 ts 文件中，然后注册到 main 中
  - 减少到 650kb
- 减少到1.42mb

## 请求优化

- 将大的第三方库拆分成多个小文件
- 浏览器支持平行加载多个文件
  - http 1.1 会限制上限，大概 6-7 个（chrome）
  - http 2 没有上限
- 超过 300kb 分一个包
- 懒加载
  - webpack magic comment
  - 使用 es 的 import() 函数
