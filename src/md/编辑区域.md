# 画布拖动和缩放

假设元素css为：
```css
.test {
    position: absolute;
    top: 10px;
    left: 10px;
    width: 200px;
    height: 100px;
}
```

## 拖动

本质是修改样式中的 top 和 left属性

- 鼠标相对位置没有发生改变
  - 计算鼠标相对元素的 top 和 left

### 实现

- MouseDown 后开始操作
- 添加 MouseMove 监控更新 top， left 的值
- MouseUp 清除事件
 
## 缩放

本质是修改样式中的 width 和 height
