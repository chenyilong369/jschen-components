# 整体设计思路

## 整体思路

- 根据 id、uuid 获取作品数据
- 判断 status （是否下线）
- 作品数据 + jschen-bricks --> 渲染出 h5 页面

## SSR

业务特点：流量大，交互简单

- 速度快
- 利用 jschen-bricks，使用 vue3 ssr
- 仅仅渲染一个 h5 页面，没有路由，交互简单，所以不用框架


## 缓存

- 流量大时，频繁访问数据库是一个性能瓶颈
- 使用 redis 缓存，可解决这个问题
- 何时清除缓存：
  - 重新发布
  - 强制下线


## 网页前端

- 统计，分渠道统计
- 渠道参数检查
- 事件
- 微信分享（分享回流）
